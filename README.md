# libft

## 説明

**libft** は、標準Cライブラリの関数群をゼロから再実装したカスタムCライブラリです。標準ライブラリにない追加のユーティリティ関数も含まれています。

このプロジェクトの目的は、メモリ操作・文字列処理・文字判定・整数変換・連結リスト管理といったCの基礎関数が内部でどのように動作するかを、標準ライブラリに頼らず実装することで深く理解することです。

完成した静的ライブラリ `libft.a` は、今後の42プロジェクトで個人ツールキットとしてリンクして使用できます。

## ライブラリ関数一覧

### Part 1 — libc関数の再実装

標準Cライブラリ関数の再実装です：

| 関数 | 説明 |
|---|---|
| `ft_isalpha` | `c` がアルファベットであれば非ゼロを返す |
| `ft_isdigit` | `c` が10進数字であれば非ゼロを返す |
| `ft_isalnum` | `c` が英数字であれば非ゼロを返す |
| `ft_isascii` | `c` が7ビットASCII文字であれば非ゼロを返す |
| `ft_isprint` | `c` が印字可能文字であれば非ゼロを返す |
| `ft_toupper` | 小文字を大文字に変換する |
| `ft_tolower` | 大文字を小文字に変換する |
| `ft_strlen` | 文字列の長さを返す |
| `ft_memset` | メモリ領域を指定バイト値で埋める |
| `ft_bzero` | メモリ領域をゼロで初期化する |
| `ft_memcpy` | メモリをコピーする（オーバーラップ非対応） |
| `ft_memmove` | メモリを安全にコピーする（オーバーラップ対応） |
| `ft_memchr` | メモリ領域から最初に一致するバイトを探す |
| `ft_memcmp` | 2つのメモリ領域をバイト単位で比較する |
| `ft_strlcpy` | サイズ制限付きでNUL終端しながら文字列をコピーする |
| `ft_strlcat` | サイズ制限付きでNUL終端しながら文字列を連結する |
| `ft_strchr` | 文字列中の最初に一致する文字を探す |
| `ft_strrchr` | 文字列中の最後に一致する文字を探す |
| `ft_strncmp` | 2つの文字列を最大 `n` 文字まで比較する |
| `ft_strnstr` | 文字列中から部分文字列を `len` の範囲内で探す |
| `ft_atoi` | 文字列を整数に変換する |
| `ft_calloc` | ゼロ初期化されたメモリを確保する |
| `ft_strdup` | `malloc` を使って文字列を複製する |

### Part 2 — 追加ユーティリティ関数

標準libcには存在しない独自ユーティリティ関数です：

| 関数 | 説明 |
|---|---|
| `ft_substr` | 文字列の部分文字列を確保して返す |
| `ft_strjoin` | 2つの文字列を結合して新たに確保した文字列を返す |
| `ft_strtrim` | 文字列の両端から指定文字を除去する |
| `ft_split` | 区切り文字で文字列を分割し `NULL` 終端の配列を返す |
| `ft_itoa` | 整数を文字列に変換する |
| `ft_strmapi` | 文字列の各文字に関数を適用し新しい文字列を返す |
| `ft_striteri` | 文字列の各文字にインデックス付きで関数を適用する（インプレース） |
| `ft_putchar_fd` | ファイルディスクリプタに1文字を出力する |
| `ft_putstr_fd` | ファイルディスクリプタに文字列を出力する |
| `ft_putendl_fd` | ファイルディスクリプタに文字列と改行を出力する |
| `ft_putnbr_fd` | ファイルディスクリプタに整数を出力する |

### ボーナス — 連結リスト関数

片方向連結リスト（`t_list`）を操作するための関数です：

| 関数 | 説明 |
|---|---|
| `ft_lstnew` | 新しいリストノードを確保して返す |
| `ft_lstadd_front` | リストの先頭にノードを追加する |
| `ft_lstadd_back` | リストの末尾にノードを追加する |
| `ft_lstlast` | リストの最後のノードを返す |
| `ft_lstsize` | リストのノード数を返す |
| `ft_lstdelone` | 指定した `del` 関数を使い単一ノードを削除する |
| `ft_lstclear` | リストの全ノードを削除・解放する |
| `ft_lstiter` | リストを走査し各ノードのコンテンツに関数を適用する |
| `ft_lstmap` | 各ノードに関数を適用し変換された新しいリストを返す |

## 使い方

### コンパイル

```bash
make
```

カレントディレクトリに `libft.a` が生成されます。

### 別プロジェクトへのリンク

```c
#include "libft.h"
```

```bash
cc your_file.c -L. -lft -o your_program
```

### Makefileのルール一覧

| ルール | 内容 |
|---|---|
| `make` / `make all` | ライブラリをコンパイルする |
| `make clean` | オブジェクトファイルを削除する |
| `make fclean` | オブジェクトファイルと `libft.a` を削除する |
| `make re` | フルリビルドする |
| `make bonus` | `all` と同じ（ボーナス関数はデフォルトで含まれる） |
